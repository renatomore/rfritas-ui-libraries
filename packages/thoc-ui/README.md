## (EN-US)

A React component library for building modern, accessible, and consistent user interfaces.

### Description

Thoc UI is a set of reusable React components designed to accelerate the development of web applications. It is built with TypeScript and styled-components, offering a great developer experience and high customizability.

### Installation

To use Thoc UI in your project, install the package via npm:

```bash
npm install @rfritas/thoc-ui
```

### Usage

Import the components you need and start using them in your application.

```jsx
import React from 'react';
import { Button } from '@rfritas/thoc-ui';

function App() {
  return (
    <div>
      <h1>Welcome to Thoc UI</h1>
      <Button>Click Me</Button>
    </div>
  );
}

export default App;
```

### Components

Thoc UI provides a variety of components to build your application. Here are some of them:

-   **Button**: For user actions.
-   **Input**: For text entry.
-   **Card**: To group related content.
-   **Modal**: To display content in a layer above the app.
-   **Spinner**: To indicate a loading state.
-   ...and many more to come!

## (PT-BR)

Uma biblioteca de componentes React para construir interfaces de usuário modernas, acessíveis e consistentes.

### Descrição

Thoc UI é um conjunto de componentes React reutilizáveis projetados para acelerar o desenvolvimento de aplicações web. É construído com TypeScript e styled-components, oferecendo uma ótima experiência de desenvolvimento e alta customização.

### Instalação

Para usar o Thoc UI em seu projeto, instale o pacote via npm:

```bash
npm install @rfritas/thoc-ui
```

### Como Usar

Importe os componentes que você precisa e comece a usá-los em sua aplicação.

